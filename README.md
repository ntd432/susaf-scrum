# ImpactAgile: Integrating Sustainability into Agile Workflows

##  Why ImpactAgile? 
Many Agile teams today want to prioritize sustainability, but lack the tools to do it effectively in our knowledge. ImpactAgile was born to close this gap. We created a web-based project management platform that embeds sustainability directly into Scrum workflows—leveraging AI, real-time metrics, and behavioral science. Our vision goes beyond tools; ImpactAgile is a blueprint for responsible, future-proof software development.

## Design
ImpactAgile emphasizes behavioral design to make sustainable practices second nature: 
- Color-Coded Kanban Board 
Tasks with high sustainability impact are visually tagged for prioritization.
- Familiar UI, Powerful Additions 
Mirrors Jira’s layout but introduces Sustainability Points as a visible KPI. 
- Nudge Alerts 
Users receive real-time prompts like “You didn’t check the sustainability tick for this task.” 
- Knowledge Hub 
Offers bite-sized educational content, resources, and sustainability best practices—accessible in the workflow.

## Key Features
1. Generate User Stories
   - Converts uploaded SusAF impact files into sustainability-tagged user stories.
   - Assigns both Story Points (effort) and Sustainability Points (impact). 
2. Sprint Planning
   - AI suggests sprint goals that align with sustainability objectives.
   - Prioritization board emphasizes high-impact tasks with visual cues. 
3. Task Tracking (Kanban)
   - Columns: To Do → In Progress → In Review → Done.
   - Sustainability Blockers prevent incomplete tasks from being closed without meeting green criteria. 
4. Sprint Retrospective
   - Interactive checklist prompts:
     - “Did we meet our sustainability goals?”
     - “Were best practices applied throughout the sprint?”
5. Sustainability Hub
   - Manual: Comprehensive tool documentation.
   - Educational Resources: FAQs, UN SDG mapping, microlearning content, and case studies.
